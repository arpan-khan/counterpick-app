# CounterPick

An Android app for browsing and managing counter-pick data for MLBB.

(UI Vibe Coded)

## Tech Stack

- **Language**: Kotlin
- **UI**: Jetpack Compose + Material 3
- **Navigation**: Navigation Compose
- **Local DB**: Room
- **Networking**: OkHttp + kotlinx.serialization
- **Images**: Coil
- **Min SDK**: 24 · **Target SDK**: 35

## Getting Started

1. Clone the repo
2. Open in Android Studio
3. Build & run on a device or emulator (API 24+)
